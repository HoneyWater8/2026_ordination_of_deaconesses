## 판단한 것

**1. `FE-legacy/`에는 이번 프로젝트분만 — 사용자 결정**

번들은 세 프로젝트 묶음이었고, 대조해 보니 02(졸업)는 졸업 레포 `FE-legacy/`와 바이트 단위로 같고 01(가족 한마당)은 줄바꿈만 다른 같은 내용을 폴더만 재배치한 것이었습니다. 관례는 "zip을 원본 그대로"였지만 사용자가 이번 프로젝트분만 두기로 정했습니다. 원본이 평면 구조라 `final/`·`explorations/`로 나누었고, 시안 HTML들이 공용 `ordain-app.jsx`·`ordain-data.js`를 같은 폴더에서 불러오므로 `explorations/`에도 같은 사본을 두었습니다 — 졸업 레포는 `explorations/`에 `grad-data.js`가 없어 시안이 실행되지 않는 상태로 보관되어 있습니다.

README는 원본 본문을 그대로 두고 「Files」 절만 새 경로로 고쳤습니다. `DESIGN_PROCESS.md`는 원본에 없어 확인된 사실만으로 새로 썼고, **기록에 없는 선정 이유는 쓰지 않았습니다.**

**2. 스크린샷은 평소 모션으로**

촬영 스킬 기본값은 모션 감소(reduce)인데, 그러면 시안의 떨어지는 꽃잎이 섹션 위쪽에 멈춘 채 찍혀 실제 모습과 다릅니다. 평소 모션으로 두고 각 섹션을 한 번씩 지나가게 해 Reveal을 소진한 뒤 찍었습니다. 이 관찰이 3-④의 근거가 되었습니다.

**3. 시안을 바꾼 곳**

| 시안 | 구현 | 이유 |

| 말씀 시트 `fixed inset:0` + body 스크롤 잠금 | 앱 폭(460px) 가운데 정렬, 잠금 제거 | `inset:0`은 데스크톱에서 앱 밖까지 덮음(졸업 Lightbox와 같은 처리). body가 원래 스크롤하지 않고 portal된 시트는 스크롤 컨테이너 밖이라 잠금이 필요 없음 |
| 달력 첫 칸 `일` | `주` | 졸업 레포 사용자 지시(2026-09-11)와 가족 한마당의 교회 관례 |

**4. 시안에 없던 것을 더한 곳 — 앞선 레포의 기록을 따름**

- 오시는 길: 실제 지도 + 카카오맵·네이버지도·T맵 + 주소 복사 — 가족 한마당과 동일 (사용자 지시). 담당자의 「(네이버 지도?)」는 네이버지도 링크로 해결
- 갤러리: 확대 보기 — 졸업. 임직자 카드는 사용자 지시로 확대하지 않음
- 20주년 기념 영상: 갤러리 사진 아래 (사용자 결정) — 졸업 「졸업 예배」 항목(사진 + 영상)과 같은 배치. 졸업의 재생 로직(누르기 전 미요청·단일 재생·전체화면 고화질)과 테스트 24개를 그대로
- 공유 버튼 — 졸업. 봉투가 없어 처음부터 보임
- 마지막 화면 하단의 저작권 + `DESIGNED & DEVELOPED BY HONEYWATER` — 두 레포의 제작자 표기와 졸업에서 사용자가 요청한 하단 배치

**5. 명단 — 원문 순서로 보관, 화면은 가나다순**

담당자 원문은 대체로 가나다순이나 두 곳이 어긋나 있고 시안은 화면에서 정렬했습니다. 사용자가 가나다순을 골랐습니다. 데이터는 받은 그대로 두고(졸업 명단처럼 출처를 보존) 화면에서 정렬하며, 사진 파일 번호를 원문 순서로 매겨 **ASCII 경로**를 유지했습니다 — 이름을 파일명으로 쓰면 URL이 한글이 됩니다.

**6. 폰트 — 졸업과 같은 부분 폰트, 이름 변경은 이번엔 필수**

시안은 Google Fonts·jsDelivr CDN으로 세 서체 전체를 받습니다. 졸업의 자체 호스팅 부분 폰트 파이프라인을 그대로 옮겨 7개 WOFF2 합계 약 249KB(한글 446자)로 줄였습니다. 원본을 받아 보니 **Pretendard는 OFL Reserved Font Name(「Pretendard」)이 있어** 부분 폰트(수정본)에 원래 이름을 쓸 수 없습니다. 졸업은 예방 차원이었던 이름 변경이 이번엔 의무라 세 서체 모두 `Ordain *`로 바꿨습니다. Cormorant Garamond는 가변 폰트라 600으로 고정한 뒤 잘랐습니다.

**7. 대비 규칙 — 졸업의 금색 규칙과 같은 구조**

계산해 보니 `accent`(#C2566A)가 bg 위 4.14:1로 작은 글씨 기준에 못 미칩니다. 시안도 실제로 46px 「임직」에만 accent를 쓰고 작은 글씨는 `label`(4.86:1)이라, 졸업의 「`EV.gold`는 24px 미만 금지」와 같은 규칙으로 토큰 주석에 박았습니다.

**8. 썸네일은 만들지 않음**

졸업은 썸네일 없이 첫 배포를 해 공유 카드에 이미지가 없었습니다. 그래서 첫 화면을 잘라 만들려다가 사용자가 직접 만들겠다고 해 중단했습니다. `og:image`는 `/icons/thumbnail.png`를 가리킵니다.
