## 판단한 것

**1. 우슬초도 함께 뺌**

우슬초는 예배 순서 섹션에만 쓰였고, 해설도 "예배의 순서 앞에서 먼저 마음을 정결히 준비합니다"로 그 섹션을 위한 글이었습니다. 남겨 두면 쓰이지 않는 글이 「?」 해설글 검토 대상(담당 전도사에게 보낼 남은 과제 3번)에 섞입니다. 그림 원본은 `FE-legacy/final/ordain-flowers-bible.jsx`에, 구현은 git 히스토리에 있습니다.

**2. 섹션 라벨 번호를 당기지 않음**

라벨(`05 Ordainees` …)은 GA 집계 키이면서 `SectionFlowers`가 배경 꽃의 좌우·기울기·흔들림 주기를 정하는 시드입니다(글자 코드 합). 번호를 하나씩 당기면 합이 1씩 줄어 네 섹션(임직자·오시는 길·갤러리·안내)의 모서리 꽃이 모두 좌우로 뒤집힙니다 — 직접 계산해 확인했습니다. 사용자가 이미 본 화면이 이유 없이 바뀌므로 번호는 그대로 두고 04를 비워 둡니다. GA4는 아직 측정 ID가 없어 쌓인 데이터는 없습니다.

**3. 배경 교차는 마지막 화면까지 다시 맞춤**

첫 화면(bg) 뒤로 본문 섹션과 마지막 화면이 bg2 · bg로 번갈아 나오던 구성이 본문 7개 → 6개가 되며 한 군데에서 같은 색이 이어질 수밖에 없게 됐습니다.

| 안 | 같은 색이 이어지는 곳 | 바꾸는 곳 |
|---|---|---|
| 그대로 | 03 예배 일시 → 05 임직자 | 없음 |
| 05~08만 뒤집기 | 08 안내 → 마지막 화면 | 4곳 |
| **05~08 + 마지막 화면** | **없음** | 5곳 |

05~08만 뒤집은 안을 먼저 렌더링해 보니, 안내 카드 아래부터 마지막 꽃까지 경계 없는 빈칸이 화면 하나 가까이 이어졌습니다. 두 섹션 모두 높이가 화면 하나(`min-height: 100%`)라 색이 바뀌어야 새 화면으로 읽힙니다. 그래서 마지막 화면도 bg2로 바꿔 끝까지 번갈아 나오게 했습니다. 시안의 「마지막 화면은 바로 앞 섹션과 다른 색」이라는 관계는 그대로입니다. 로고는 투명 배경이라 bg2 위에서도 테두리가 생기지 않는 것을 확인했습니다.

**4. 부분 폰트는 다시 만들지 않음**

소스 글자가 438자 → 429자로 줄었습니다. 빠진 9자는 부분 폰트에 남지만 빌드 검사는 「소스 글자가 폰트에 다 있는가」만 보므로 통과합니다. 다음에 새 글자가 생겨 `prepare-fonts.py`를 돌리면 자연히 빠집니다. 지금 다시 만들면 폰트 파일 7개가 바뀌는데 얻는 것은 수 KB입니다.
