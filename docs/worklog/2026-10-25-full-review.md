## 판단한 것

**1. 에이전트 지적은 재현한 것만 고쳤다**

`section_view` 05 누락은 실제 사이트를 3개 화면 크기로 끝까지 내려 확인했고, 두 에이전트가 따로 같은 결론을 냈습니다. GA 자동 `scroll`은 스크롤 없이 연 페이지에서도 나가는 것을 확인했습니다. 확대 보기 탭 새기는 고친 뒤 `photo_open`이 1회만 나가는 것으로 확인했습니다.

**2. 지도 — 끌기만 끄는 것으로는 안 됐다**

처음엔 카카오 API `setDraggable(false)`·`setZoomable(false)`로 고쳤는데 터치 에뮬레이션에서 지도 위 스크롤이 여전히 0px이었습니다. 지도가 입력 자체를 받지 않게(`pointer-events: none`) 하자 지도 밖과 같은 124px가 됐습니다. 지도는 위치를 보여 주는 그림으로만 쓰고 길찾기는 지도 앱 버튼 세 개가 맡습니다. 가족 한마당(출처)과 다른 동작이라 CLAUDE.md 「되돌리면 안 되는 것」에 이유를 적었습니다.

**3. 네이버지도는 장소 ID로**

후보 세 가지를 열어 봤습니다. 장소 이름 검색은 결과 목록이고, `v5/search`는 앱 설치 페이지로 넘어갑니다. 검색 결과의 장소 ID `12158606`(개신교 · 김포한강2로 167 · 좌표가 카카오와 같음)로 연 장소 페이지가 모바일·PC 모두 이름 · 주소 · 길찾기를 보여 줘 그것으로 정했습니다. 네이버가 자동화 브라우저에 보안 확인을 띄워 요청은 몇 번으로 그쳤습니다.

**4. `robots.txt`는 두지 않았다**

검색 노출만 막으면 되고, 카카오톡 공유 미리보기 스크래퍼가 `robots.txt`를 따르면 공유 카드가 사라질 수 있습니다. 메타 태그와 응답 헤더로만 막았습니다. 헤더는 Vercel 설정이라 배포 뒤에 확인해야 합니다.

**5. 고치지 않은 것과 이유**

- 12px 미만 글자(제작자 9px · © 11px · 동명이인 「B」 10px · 확대 보기 번호 11px) — 디자인 선택이라 지적만
- `Flower.tsx`의 하드코딩 색 · 그림자 `rgba()` — 시안 팔레트와 토큰 값을 풀어 쓴 것이라 CLAUDE.md에 예외로 적었다(토큰으로 바꾸면 꽃 팔레트 수십 개 중 둘만 토큰이 된다)
- `BL.accent2`·`BL.outer`(TS에서 안 쓰임) — 디자인 토큰 표에 있는 값이라 남김. 안 쓰이는 export 타입도 해가 없어 남김
- 확대 보기·공유 시트의 완전한 초점 가두기(Tab 순환) — 열 때 초점 이동 · 닫을 때 복귀 · Esc까지만
- 탭을 연 채 자정을 넘기면 D-day가 갱신되지 않음 · iOS 13 이하 `matchMedia().addEventListener` — 영향이 작아 기록만
