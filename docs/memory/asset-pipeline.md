**원본은 저장소에 넣지 않고 줄인 사본만 커밋합니다** (졸업 레포와 같은 원칙). 사진 원본은 `assets/photo-originals/`, 폰트 원본 캐시는 `assets/font-work/` — 모두 git 제외.

| 자산 | 수령 경로 | 상태 (2026-10-24) |
|---|---|---|
| 로고 | 가족 한마당 레포 `FE/public/icons/hanaro.png` (2026-10-24 사용자 지시) | ✅ 흰 배경 제거 → `FE/src/assets/logo.webp` |
| 임직자 사진 66장 | **임직 예정자 카톡방** 자료 — 2026-10-25 사용자가 `이름.jpg`로 모아 `assets/photo-originals/ordainees/`에 저장 | ✅ 66명 반영 (2026-10-25) — `FE/public/ordainees/01~66.webp` |
| 갤러리 사진 8장 | 담당자가 대화방에 보냄 ("갤러리에는 이정도") | **파일을 사용자에게서 받아야 함** — 번호 자리 |
| 20주년 기념 영상 | 교회 YouTube 채널 — `youtu.be/1mncrNOaeOA` (2026-10-24 사용자 전달) | ✅ 임베드. 자체 호스팅하지 않음 |
| 공유 썸네일 1200×630 | 처음엔 사용자가 만들기로 했으나(10-23) **2026-10-24 사용자 요청으로 제작** — 로고·지정 문구·살구꽃 | ✅ `FE/public/icons/thumbnail-v2.png` (원본 `scripts/thumbnail.html`) |
| 탭 아이콘 | 첫 화면의 꽃(살구꽃) — 2026-10-24 사용자 지정 | ✅ `favicon-32`·`favicon-180`·`apple-touch-icon` |

**Why:** 원본은 장당 수 MB이고 화면에는 훨씬 작게만 쓰입니다. 재생성 스크립트가 있으면 원본을 커밋할 이유가 없습니다. 공개 레포이기도 합니다.

**How to apply:**

- 임직자 사진은 파일명을 `이름.jpg`로 바꿔 모은 뒤 `scripts/resize-photos.py --ordainees`. 카톡방 사진은 파일명이 무작위라 **이름 대응은 사람이 해야** 합니다. 사용자는 이름을 모르는 글자를 `X`로 적습니다(`X상연.png` → 김상연, `XXX.jpg` → 이상미로 2026-10-25 사용자 확인).
- 2026-10-25 원본은 모두 한 사람씩 찍힌 사진이었고, 얼굴 인식으로 잘랐습니다: OpenCV YuNet(`face_detection_yunet_2023mar.onnx`, opencv_zoo) → 가장 큰 얼굴의 **폭 × 2.5 정사각, 눈높이 42%** → `assets/photo-originals/ordainees-cropped/이름.jpg` → 그 폴더로 `resize-photos.py --ordainees`. 상자는 `assets/photo-originals/ordainee-crops.json`. 검출 도구는 **레포에 없습니다**(세션 임시 폴더의 venv에서 실행) — 새 사진이 오면 같은 값으로 다시 만들거나 그 사람 상자만 손으로 넣습니다.
- 이름 미상 사진은 남은 사람이 한 명뿐이어도 **추정으로 넣지 않고 사용자 확인을 받습니다** (사람 얼굴에 이름을 붙이는 일이고, 푸시하면 발주자 화면에 그대로 나감). 사진 한 장을 바꾸거나 더할 때는 그 한 장만 자른 폴더로 `resize-photos.py --ordainees`를 돌립니다 — 기존 출력을 덮어쓰지 않으므로 전체 폴더를 넣으면 멈춥니다(교체면 `--force`).
- 갤러리 장수는 `photosOf('gallery', N, '갤러리')`의 N만 고칩니다.
- 영상은 YouTube 임베드라 우리 쪽 전송량이 없습니다. 졸업 레포의 자체 호스팅 모듈(영상 슬롯·전체화면 화질 전환·테스트)은 2026-10-24 걷어냈습니다. 나중에 자체 호스팅 영상이 생기면 졸업 레포에서 다시 가져오되, Vercel Blob 전송량 한도 초과로 차단된 경위(2026-09-26 → Cloudflare R2)를 먼저 읽습니다.
- 썸네일 문구는 사용자가 지정한 것입니다 (하나로교회 / Ordination Thanksgiving Service / 권사 임직 / 감사예배 / 11월 8일 주일·오후 2시 / 김포 하나로교회 B2 다윗성전). 가운뎃점은 첫 화면과 같은 「 · 」로 맞췄습니다. **크기는 앞선 레포 썸네일 비율을 따릅니다** — 첫 화면 비율 그대로(제목 62px, 글자 영역 폭 298px)는 사용자가 "글씨가 너무 작아서 여백이 너무 많다"며 고치게 했고(2026-10-24), 제목 112px · 글자 영역이 세로 74%(졸업 썸네일 72%)인 안으로 바꿨습니다. 다시 만들 때는 `scripts/thumbnail.html`을 고쳐 1200×630·DPR 2로 캡처 → 1200×630으로 줄입니다. 폰트는 원본 캐시(`assets/font-work/`)를 직접 읽으므로 캐시가 있어야 합니다. **교체할 때는 반드시 파일명을 새로 하고 `og:image`·`twitter:image`를 함께 바꿉니다** — 같은 경로로 교체했더니 공유 디버거에서 캐시 초기화를 여러 번 눌러도 옛 이미지가 나왔습니다(2026-10-24, 서버는 새 파일을 내보내고 있었음). 졸업 레포에서 같은 경로 교체가 괜찮았던 것은 그때 우연이었던 것으로 봅니다.
- 로고 원본은 흰 배경이 꽉 찬 PNG이고 붉은 띠 안의 글자도 흰색입니다. `scripts/prepare-logo.py`는 붉은 띠로 둘러싸인 영역만 원본대로 두고 나머지를 「흰색 → 투명」으로 바꿉니다 — 흰색을 일괄로 지우면 띠 글자에 구멍이 뚫립니다.
- 탭 아이콘은 스크립트가 없습니다(브라우저 렌더링이 필요). 만든 방법: 빌드한 페이지에서 첫 화면 구분선의 살구꽃 SVG(46px)를 1024px로 렌더링 → 알파 경계로 잘라 정사각 여백 8% → 32·180px 투명, `apple-touch-icon`만 배경 `#FFF8F4`. 32px에서는 꽃가지가 작고 옅습니다 — 꽃송이만 자른 안도 비교했지만 꽃이 좌우로 퍼져 있어 개선이 작았습니다.
- 지도 앱·카카오톡 아이콘은 가족 한마당에서 가져와 표시 크기의 3배(84px·60px)로 줄였습니다(51KB → 4.9KB 등).
- 폰트 원본은 커밋 해시로 고정한 URL에서 받고 SHA-256을 검사합니다. 캐시가 없으면 `prepare-fonts.py --download`.
