2026-10-25 전체 검토에서 공개 범위를 점검했습니다.

| 경로 | 상태 |
|---|---|
| 사이트 검색 노출 | ✅ 막음 — `index.html` `noindex` 메타 + `vercel.json` `X-Robots-Tag`(사진 파일까지). 검토 시점에 검색 결과에는 없었음 |
| GitHub 저장소 `HoneyWater8/2026_ordination_of_deaconesses` | **공개 유지 — 2026-10-25 사용자 결정** (비공개 전환을 제안했으나 하지 않기로 함). 명단·사진 66장·익명화 대화 기록을 누구나 받을 수 있다는 점은 안내함. 앞선 두 레포도 공개 |
| 원본 사진 · 원본 카톡 · `.env.local` | ✅ git 기록 전체에 한 번도 커밋된 적 없음 (`git log --all` 확인) |
| 공개 사진의 위치·촬영 정보(EXIF/XMP) | ✅ 없음 |
| 운영 기간(언제 내릴지) | ⏳ 미정 |

**Why:** 초대장은 링크를 받은 사람만 보면 되는데, 실명과 얼굴이 함께 있어 한 번 색인되거나 퍼지면 되돌리기 어렵습니다.

**How to apply:**

- `robots.txt`는 만들지 않습니다 — 카카오톡 공유 미리보기 스크래퍼가 따를 수 있어 공유 카드가 사라질 위험이 있습니다. `noindex`는 메타·헤더로만.
- 저장소 비공개 전환은 다시 제안하지 않습니다(사용자가 결정함). 공개 저장소이므로 원본 사진·원본 카톡·실명이 든 파일이 커밋되지 않게 지금처럼 커밋 전에 확인합니다.
- 운영 기간이 정해지면 위 표를 고칩니다([[vercel-deploy-setup]]).
- 사진·명단을 더 넣을 때도 원본은 커밋하지 않고 메타데이터 없는 사본만 올립니다([[asset-pipeline]]).
