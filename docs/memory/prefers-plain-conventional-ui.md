디자인 판단이 갈릴 때 **관습적이고 담백한 쪽**을 고릅니다. 졸업 레포(2026-09-07~09-22)에서 컨셉 일관성을 위해 더한 장식은 전부 되돌려졌습니다 — 씰이 찍히는 진입 연출, 각진 바텀시트·토스트, 시트 상단 금박선, 「아래로 넘겨보세요」(→「아래로 스크롤」), 라이트박스 고정 틀. 봉투가 열리는 속도를 바꿨을 때도 원래 속도로 복원을 요청했습니다.

**Why:** 전 교인이 보는 초대장이라 연령대가 넓고, "예쁜 장치"보다 바로 알아보는 것이 우선입니다. 핸드오프 토큰은 콘텐츠의 시각 언어이지 기능적 UI(시트·토스트·버튼)에 기계적으로 적용할 규칙이 아닙니다.

**How to apply:**

- 새 UI 요소는 먼저 그 플랫폼의 관습대로. 컨셉 각색은 색·서체·테두리 선에서 그칩니다.
- 장식을 하나 더 얹고 싶을 때는 넣지 말고 **먼저 제안**합니다.
- 문구는 은유보다 **동작을 그대로 말하는 쪽**으로.
- 눈에 보이는 결함이 구조적 깔끔함을 이깁니다.
- 이 프로젝트의 시안(성경 속 꽃)은 사용자가 고른 hifi 디자인이므로 꽃 연출 자체는 그대로 재현합니다. 위 원칙은 **시안에 없는 것을 더할 때** 적용합니다.
